# --- Sound timing (FS and ARM7 native, alone or combined): which pooled voice handle a sound uses ---
# Each kart object starts with a sound emitter: +0 prev, +4 next, +8 owner (0x0217D008), +0xC/+0x10 first/last
# voice handle (28-byte entries of the pool in SoundState, 0x0217C8FC..0x0217CA30), +0x14 flags|count. A handle
# is reused when the ARM7 sound driver reports the voice done; both native switches move that report by a few
# ARM7 bursts, so the same sounds get other handles and a voice may count as active one frame longer or
# shorter (+0x14). Positions, physics, items and the race RNGs stay equal.
0x0236d938-0x0236d944 kart 0 sound emitter voice-handle list and count (+0xC..+0x18): handle allocation follows ARM7 sound timing
