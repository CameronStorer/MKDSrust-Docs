# IRQ delivery at safe points / ARM7 interleaving (not game state):
0x023fffe0-0x023ffff0 shared cartridge/card lock words (0x027FFFE0/E8 mirror): owner at the V-blank sample depends on IRQ timing
region pxi PXI words per logical frame: IPC replies are delivered at the next safe point, so traffic moves between adjacent frames
region spu ARM7 SPU writes per logical frame: follow the PXI sound commands, which move with IPC delivery
region io2d_a 2D registers at the V-blank sample: exact takes V-blank mid-update where the main loop overran; native at the next safe point
