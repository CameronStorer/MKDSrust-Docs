# Function dictionary

What each of the game's functions does, as far as we know it. This is block 3 of the project (`4_docs/BLOCK3_PLAN.md`).

The dictionary holds only our own research: addresses, sizes, names, signatures and prose. It contains no code, data
or text from the game. The builder puts it to work on your machine:
- **Comments in the generated source.** Every generated function gets its dictionary line as a comment, e.g.
  `// FX_Div(a:fx32, b:fx32) -> fx32: ...`.
- **Native functions.** A function whose entry is `native-verified` runs as readable Rust from
  `2_native_game/src/native/` instead of its translation. The game installs only those (`recomp::native::VERIFIED`).

## Files
| File | Contents |
|---|---|
| `functions.csv` | One row per function the builder translates. Generated by `export.py` from the mapping project's tables; don't edit it by hand |
| `structs.csv` | Structure layouts (name, size, where the structure is found, description) |
| `sdk_functions.csv`, `game_*.csv` | Hand-refined rows. They override `functions.csv` by address; files are applied in name order |
| `export.py` | The exporter. It drops ROM strings and links into the hand port, and fails if any slip through |

Columns: `address, segment, size, name, kind, area, args, returns, sig, status, confidence, notes`.

`args` and `returns` start out filled by the generator's argument/return analysis (`sig` = `auto`), which looks at
which registers each function reads and what its callers use afterwards. `returns` means what the callers use:
`void` means no caller reads a result, empty means there is no direct caller, and `u64` means callers also read r1.
Rows refined by hand override these.

`status` describes how far each function has got:

| Status | Meaning |
|---|---|
| `unknown` | Nothing known yet |
| `described` | Notes only |
| `named` | Has a real name |
| `typed` | Has arguments and a return type |
| `native` | Has a native version, still on trial |
| `native-verified` | Its native version passed the shadow checker over whole races |

## Native functions on trial
Set `MKDS_NATIVES` before running the game or a tool:
- `MKDS_NATIVES=all` runs every native function, including those on trial.
- `MKDS_NATIVES=off` runs the exact translation everywhere.
